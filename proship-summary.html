💬 Sales Script — วิธี Pitch & Close
🎯 Pitch 1 — แชทเยอะ ตอบไม่ทัน
"ตอนนี้มีลูกค้าทักแชทมาเยอะไหมคะ?"
→ วันแชทช่วยลดงานแอดมินได้เยอะมากเลยค่ะ บอทจะทำหน้าที่ตอบแทน ไม่ต้องตอบซ้ำๆ ไม่ต้องสลับแชทเองค่ะ
🎯 Pitch 2 — คอมเมนต์หลุด
"ตอบคอมเมนต์ไม่ทัน ลูกค้าหลุดบ้างไหมคะ?"
→ วันแชทดึงคอมเมนต์เข้า inbox อัตโนมัติ ตอบแทนให้ ไม่ตกหล่น ไม่พลาดลูกค้าสักคนค่ะ

💬 ProShip — Sales & Support Scripts
Inbound — ลูกค้าใหม่
Step 1: Qualify
"ส่งกี่ชิ้น/วัน?" → "ใช้ขนส่งไหน?" → "มีสมาชิกกับ [ขนส่ง] แล้วยัง?"
มีสมาชิกแล้ว ✅
ผูก member ID → ขอข้อมูล → เปิด user → ส่ง login + คลิปสอน
ยังไม่มีสมาชิก
ขอข้อมูล → ประสานขนส่ง → รอได้ราคา → เปิด user
Support — ปัญหาที่พบบ่อย
🔒 Login ไม่ได้
ขอ email → ยืนยันตัวตน → reset password ส่วนตัว
📦 ทำออเดอร์ไม่ได้
"เลือกร้านค้าก่อนแล้วหรือยังคะ?" → ถ้าไม่ได้ → ขอ email
🖨️ ปริ้นไม่ได้/ช้า
ใช้ Chrome? → ล้างแคช Ctrl+Shift+Del → ถ้ายัง → ขอ email
📮 สแกน Barcode ไม่ได้
ขอรูปลาเบล → ถ้าชัดแล้วยังไม่ได้ → ให้ขนส่งเปลี่ยนเครื่องสแกน
