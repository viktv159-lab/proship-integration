💬 Sales & Support Scripts
Inbound — ลูกค้าใหม่สนใจ
Step 1: Qualify
"ปกติพี่ส่งของวันละกี่ชิ้นอยู่คะ?" → "แล้วตอนนี้ส่งกับขนส่งไหนอยู่คะ?" → "มีสมาชิกกับ [ขนส่ง] อยู่แล้วไหมคะพี่?"
มีสมาชิกแล้ว ✅
นำ member ID ผูกระบบ → ขอ ชื่อ/email/เบอร์/ที่อยู่ → เปิด user → ส่ง login + คลิปสอน
ยังไม่มีสมาชิก
ขอข้อมูล → ประสานขนส่ง → รอได้ราคา → เปิด user
Support — ปัญหาที่พบบ่อย
🔒 Login ไม่ได้
"รบกวนแจ้งอีเมลที่ใช้ login ให้หน่อยนะคะ" → ยืนยันตัวตน → reset password ส่วนตัว
📦 ทำออเดอร์ไม่ได้
"พี่เลือกร้านค้าก่อนสร้างรายการแล้วหรือยังคะ?" → ถ้ายังไม่ได้ → ขอ email เพื่อเช็คในระบบ
🖨️ ปริ้นไม่ได้ / ระบบช้า
"ใช้ Google Chrome ไหมคะ?" → ล้างแคช (Ctrl+Shift+Del) → ถ้ายังไม่ได้ → ขอ email
📮 สแกน Barcode ไม่ได้
ขอรูปลาเบล → ถ้าชัดแล้วยังไม่ได้ → แจ้งให้ขนส่งเปลี่ยนเครื่องสแกน
